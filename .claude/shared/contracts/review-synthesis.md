# 复盘综合契约

## 适用范围

本契约适用于周报、月报和项目复盘的综合层。综合层负责主题归并、交叉验证、方向校准和最终报告，不复制粘贴各视角段落。

## 稳定报告结构

综合报告必须保留：

- YAML frontmatter
- 标题
- `## 聊天摘要`
- 复盘六问显式一级标题
- `## 质量自检`

复盘六问一级标题：

1. `## 一、回顾目标`
2. `## 二、评估结果`
3. `## 三、分析原因（正向）`
4. `## 四、分析原因（负向）`
5. `## 五、重来演练`
6. 周报使用 `## 六、下周规划`，月报使用 `## 六、下月规划`，项目复盘使用对应后续规划标题。

## 规则层级

### 硬质量门

重要结论必须有具体证据或明确降级；会改变行动、取舍或评价的关键判断必须说明限制、反例或可信替代解释；方向锚点缺席检查和从判断推导出的可检查行动不可省略。

### 稳定导航

YAML frontmatter、标题、聊天摘要、复盘六问和 `## 质量自检` 是稳定阅读路径。六问负责定位，不要求各节等长或逐项填满。

### 判断插槽

目标漂移、主观感受、他人反馈、成功链条、自我评价偏差、目标合理性和具体手段等，只在材料出现且会改变本周期评价、重来选择或后续行动时写入。它们不是无条件覆盖清单。

### 质量自检的异常披露

`## 质量自检` 只披露会影响结论或后续行动的异常：证据不足、方向锚点不足、缺少对比基线或关键视角失败。没有这类异常时只写“质量门已通过；无影响本次判断的已知缺口。”，不得逐项复述正文已经给出的合规状态。

## 六问写作协议

### 一、回顾目标

可按判断插槽覆盖当前方向锚点、原始目标、实际追求目标（若有漂移）、目标合理性，以及与上周期追踪或假说的关系（如有）。

### 二、评估结果

可按判断插槽覆盖客观结果、主观感受、他人反馈（若有）、达成度判断和验证沉淀结果；方向锚点完成度 / 缺席项检查仍属于硬质量门。

### 三、分析原因（正向）

可按判断插槽覆盖超预期部分、成功链条、被用户忽略或值得保留的优势，以及哪些做法值得放大。

### 四、分析原因（负向）

可按判断插槽覆盖不符合预期部分、根因分析和自我评价偏差；会改变行动、取舍或评价的关键判断仍须满足证据边界 / 反例要求。

### 五、重来演练

可按判断插槽覆盖如果重来一次会保留什么、会提前调整什么、最小替代动作是什么。`重来演练` 必须独立成节，不能并入规划。

### 六、后续规划

可按判断插槽覆盖下周期目标、手段路径、检查方式 / 检查点、待验证假说、重要缺席项的硬约束或补记录要求；保留的行动必须可检查。

## 判断驱动展开

六问是稳定导航，不是逐栏填空表。每节只写会改变本周期评价、重来选择或后续行动的判断；同一证据不得跨节重复铺陈。

没有新增判断时，可用一句话说明“无新增判断”并转入下一节；不得为了覆盖清单补写目标、感受、他人反馈、优势或偏差。上述质量要素只在材料出现且会改变判断时覆盖。

展开深度由证据强度和决策影响共同决定：存在证据冲突、关键取舍、策略调整或高风险不确定性时展开；背景事实、重复证据和不改变行动的信息压缩或省略。

不可省略的是硬质量门：重要结论的证据或降级、关键判断的反例或限制、方向锚点缺席检查，以及从判断推导出的可检查行动。不为覆盖清单而重复正文。

## 方向锚点缺席检查

对每个方向锚点检查本周期是否有行动证据。缺席项本身不是失败，而是需要用户确认的校准信号。

状态只能使用以下五类：

- `有推进`：日志、日反馈或视角分析中有明确行动证据。
- `缺席-未执行`：方向重要，但缺少行动证据，且有拖延、替代投入或计划落空证据。
- `缺席-未记录`：用户提到做了，但日志缺少过程、数量或结果。
- `目标变化`：材料显示该方向已被用户主动降级或替换。
- `证据不足`：无法判断，需下周期补记录。

如果方向锚点是“考公 / 行测 / 申论 / 作息稳定”等长期主线，而本周期主主题没有覆盖它，必须在报告中显式说明它的状态，不能因为主题归并或轻量化而自然消失。

## 主题综合原则

1. 六问是稳定导航，不得被其他一级标题替代；主题只能在六问内部归并。
2. 主题综合只能发生在六问内部，不能反过来取代六问。
3. 材料按主题组织，不按视角顺序展开。
4. 每个重要结论都要落到具体日期、原文或视角证据。
5. 会改变行动、取舍或评价的主题必须写出反例、限制条件或“证据不足”；背景事实不为形式另起免责声明。
6. 复盘不只检查发生了什么，也检查重要但缺席了什么。
7. 如果没有显著矛盾或证据不足，如实记录，不强行制造。

用户明确要求“依据第一性原理分析”、复核或压缩既有复盘时，读取 `.claude/shared/contracts/first-principles-analysis.md`。复核结果必须归入聊天摘要或复盘六问的对应章节，不新增一级标题。

## 周报深度

1. 周报是“小月报”：仍保留复盘六问，但只聚焦 `1-3` 个重点。
2. 原因分析只做 3Why，不深挖到月度级信念层。
3. `## 六、下周规划` 至少包含“目标 + 手段 + 检查方式”。
4. 周报优先把本周日反馈中的行动验证、证伪和连续没做项沉淀为下周最小实验。

## 月报深度

1. 月报在正式写报告前先归并 `2-3` 个主主题。
2. 每个保留主题补齐主题名、支持视角、关键证据、反例或证据不足说明、对重来演练或下月规划的意义。
3. `## 六、下月规划` 必须包含“目标 + 手段 + 检查点 + 假说”。
4. 如果本月材料显示长期方向冲突、重复卡点、工作观 / 人生观冲突，或下月规划只能做局部修补，必须在 `## 六、下月规划` 中增加一条基于证据的升级提醒：

```text
⚠️ 这可能不是普通执行问题：[用一句话点出证据]。建议输入 /life-design --quick 做一次人生设计校准。
```

不要自动生成 life-design 报告。
