# 知己

> 写下真实经历，看见反复出现的模式，尝试一个小行动，再用后续结果判断它是否真的适合你。

知己是面向中文个人日志的 AI 复盘工具。它的目标不是生成更多报告，而是完成一个短闭环：

```text
记录 → 发现模式 → 形成行动 → 后续验证 → 沉淀认识
```

## 第一次使用：完成一个最短闭环

你需要一个能打开整个项目目录、读取项目指令并读写 Markdown 的 AI 工具，例如 Codex 或 Claude Code。不要只打开单个文件。

请勿写入不愿交给当前 AI 服务商处理的敏感信息；真实日志默认不会进入 Git，但这不是加密或访问控制。

直接粘贴一段真实日志，然后发送：

```text
分析这篇日志。请只给我一个最关键的洞察、一个可验证的小实验，并说明下次应该记录什么。
```

例如，你可以写：

```text
日志：今天本来要完成方案，但我一直整理资料，直到晚上也没开始正文。
```

下一次记录时补充：

```text
上次实验：[做了 / 没做 / 做了一部分]
结果：[发生了什么]
判断：[支持原假说 / 出现反例 / 仍待验证]
```

这就完成了“日志 → 洞察 → 小实验 → 结果”的第一次闭环。

## 日志与结论如何使用

日志不必套模板；用 `日志：`、`日记：` 或 `记录一下：` 开头的自由叙事都可以。发生了什么、当时感受、实际行动、结果差异和不确定之处，会让分析更可靠。

AI 给出的模式是等待验证的行为假说，不是对你的定论。证据不足时，它应明确降低结论强度；一次实验没奏效，也只说明这次方法未奏效，而不能直接证伪假说。你始终决定采纳、修改或拒绝建议，并保留对自身经历和重大选择的最终解释权。

## 按需要使用其他能力

| 你的目的 | 可以直接这样说 | 兼容命令 |
|----------|----------------|----------|
| 不知道从哪里开始 | 帮我判断这些材料最适合做什么复盘 | `/review` |
| 做今天的日反馈 | 帮我做今天的日志反馈 | `/daily-review today` |
| 改进日志质量 | 看看最近几天的日志质量，只告诉我优先改进什么 | `/journal-coach` |
| 回顾一周 / 一月 / 项目 | `生成 2026-W28 周报` / `生成 2026 年 6 月月报` / `对 X 做项目复盘` | Claude 可用 `/weekly-review`、`/monthly-review`、`/project-review` |
| 回顾全年 | 基于今年月报做年度回顾 | `/yearly-review` |
| 校准长期方向 | 我想重新检查最近的生活方向 | `/life-design --quick` |

年度回顾依赖足够的月报材料；材料不足时，先完成最近一次日反馈、周报或月报更有价值。人生设计适用于长期目标、生活结构或价值选择持续冲突的情况。

想讨论会长期演化的观点时，可以说“先不要保存；形成明确认识后，再问我是否写入主题思考库”。只有你确认后，系统才会在 `关于我/思考/` 保存主题。想保存文章或摘录时，说“收录到收藏吃灰库/健身：”并附上内容或链接即可。

## 结果保存与隐私

| 目录 | 内容 |
|------|------|
| `日志/` | 原始日志 |
| `复盘/每日反馈/` | 日反馈和日志教练报告 |
| `复盘/每周复盘/`、`复盘/每月复盘/`、`复盘/项目复盘/` | 周、月与项目复盘 |
| `复盘/年度回顾/`、`复盘/人生设计/` | 长期回顾与方向校准 |
| `关于我/` | 长期上下文、验证沉淀与确认后的主题思考 |

如果会填写真实画像，首次填写前运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/protect-private-data.ps1
```

它会在当前克隆中将相关种子文件标记为 `skip-worktree`，减少误提交风险；换电脑或重新克隆后需再次执行。

## 常见问题

**AI 说得很有道理，要直接相信吗？** 不要。检查它引用的日志事实、寻找反例，并用后续行动验证。

**没有按建议行动，是失败吗？** 不是。“没做”也是信息，可能说明行动门槛、时机或假说需要调整。

**日志很短还能分析吗？** 可以，但结论应更保守；补充一两项事实、感受、行动或结果即可。

**找不到文件怎么办？** 确认 AI 打开的是整个知己目录；也可以直接粘贴正文后要求保存和分析。

## 当前版本与验证状态

当前用户版对应 `v1.9.7`。关键路径和分发边界已通过自动检查；长期分析质量仍需以更多真实日志验证。结论与你的实际经历不符时，应以你的当前表达和后续证据为准。
