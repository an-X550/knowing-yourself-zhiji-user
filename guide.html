详细使用说明

从一件困扰你的事开始

这页集中说明首次使用步骤、主要功能，以及飞书、手机记录入口和滴答清单的用途。第一次使用时，只需要完成第一部分。

查看首次使用步骤

首次使用步骤

  1. 保存整个 zhiji-user 文件夹。
  2. 用 Codex 或 Claude Code 打开这个文件夹。
  3. 写一件最近让你困扰、想推进却没推进，或想改变的具体事情。
  4. 下次记录时补充：你有没有试建议，发生了什么。
请帮我看看这段记录：哪些内容是已经发生的事，哪些只是我的猜测？
再给我一个下次可以试的简单做法。

日志：今天本来要完成方案，但我一直整理资料，直到晚上也没开始正文。

你可以用它做什么

想清最近的一件事

例如迟迟没开始做事、总是熬夜、情绪反复，或一段关系让你不舒服。它帮你找到一个值得关注的点和下次可以试的做法。

回顾一段时间

当你想知道一周、一个月或一个项目里什么有效、什么反复发生时，把多篇记录放在一起看。

把日志写得更有用

不知道该写什么时，让它只告诉你下一次最值得补的一类信息。

整理长期想法和资料

讨论一个问题，确认后保存；也可以保存文章、摘录和链接，方便以后找到。

飞书、手机记录入口和滴答清单

它们都不是必需的。只有你已经愿意持续使用、希望减少重复操作时才考虑配置。

可选，默认关闭

飞书：保存重要结果

把你想保留的回顾、计划和想法整理到飞书“知己”文件夹，手机和电脑都能查看。

查看飞书保存设置

可选，默认关闭

手机记录入口

外出时，可以在飞书私聊机器人发送 日志：内容，让电脑上的知己生成每日反馈。电脑、网络和监听程序必须保持在线，通常需等 2–5 分钟。

查看手机记录入口设置

可选，默认关闭

滴答：保存下一步行动

把反馈中明确可做的下一步放进“知己行动”清单，并设置截止时间；它不会读取或修改你其他任务。

查看滴答 / TickTick 设置

隐私和边界

  • 只写愿意交给当前 AI 服务处理的内容。
  • AI 的建议不是诊断或最终结论；你决定是否采纳。
  • 电脑里的笔记是原始记录。飞书或滴答连接失败，不会删除你的本地笔记。
  • 不要把密码、密钥或隐私内容放进聊天或项目文件。
