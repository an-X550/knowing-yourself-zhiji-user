# AI 分析质量标准

本页给使用者说明如何判断一份分析是否有用；它不替代运行时共享契约。

一份合格分析只需回答四件事：

1. **事实是什么**：重要判断能对应具体日期、原文或明确材料。
2. **判断是什么**：区分事实、推断与证据不足，不把猜测写成结论。
3. **为什么重要**：只保留会改变评价、选择或行动的信息，删除背景复述和同义重复。
4. **接下来如何验证**：给出可检查的下一步，后续材料能支持、削弱或推翻这个判断。

日反馈应短、只保留一个洞察和一个原子行动；周/月/项目复盘使用复盘六问，但不必逐栏填满。材料不足、关键反例、方向锚点缺失或缺少对比基线会影响结论时，应明确披露。

运行时权威规则：

- 日反馈：`.claude/shared/contracts/daily-feedback.md`
- 复盘：`.claude/shared/contracts/review-synthesis.md`
- 证据与验证沉淀：`.claude/shared/contracts/evidence-and-verification.md`
- 聊天摘要禁用词：`.claude/shared/banned-phrases.json`

使用者不需要检查评分、固定百分比、规定层数的追问或课程模板；这些形式本身不能证明分析会带来更好的下一步。
