# 写日志的最小方法

日志的目的不是完成模板、获得评分或证明成长，而是留下足以支持后续判断与行动验证的材料。

## 六个可选观察点

自由叙事同样有效；以下项目是帮助补足信息的观察点，不是固定栏目或评分表。

1. **事实**：发生了什么，涉及谁、什么情境、什么结果。
2. **重点**：今天最值得保留的一两件事，而非按时间流水账罗列。
3. **状态与结果**：自己有什么感受、进展或阻碍；区分感受和已发生的事实。
4. **思考**：对原因、取舍或模式的一个暂定解释；没有证据时保留不确定性。
5. **下一步**：一个能在近期观察是否做到的具体行为。
6. **外部校验（可选）**：与他人讨论、获得反馈或接触新信息。没有这一项不代表日志质量差。

## 最小质量检查

- 不把缺少命名栏目当成材料不足；先看是否有等价事实与行动证据。
- 不把未记录某件事推断为没有发生。
- 不用“更努力”“调整状态”替代可执行、可检查的下一步。
- 记录不足时，优先补一个事实、结果或行动证据，不强行写洞察。
