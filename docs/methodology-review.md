# 复盘的最小方法

复盘的目的不是填满模板或给过去打分，而是依据事实修正下一周期的选择。

## 复盘六问

1. **回顾目标**：当时想达成什么，目标或优先级后来是否变化？
2. **评估结果**：发生了什么，和预期的关键差异是什么？
3. **分析原因（正向）**：哪些做法有效，什么证据支持复用？
4. **分析原因（负向）**：哪里没有达到预期，可能原因、反例和证据边界是什么？
5. **重来演练**：若重做一次，最早会改变哪个可控选择？
6. **后续规划**：下周期保留、停止或尝试什么，以及如何检查结果？

## 使用边界

- 只展开会改变本周期评价、重来选择或后续行动的判断；没有新判断时可以简写。
- 重要结论应有日期、原文或可靠材料支撑；材料不足时明确写“证据不足”。
- 区分事实、推断和用户自己的价值取舍。AI 可以指出证据缺口与替代解释，不能代替用户决定方向。
- 下周期行动应具体且可检查；不要以完整度为由罗列任务或重复同一判断。

运行时的报告结构、方向锚点、反例和行动质量门，以 `.claude/shared/contracts/review-synthesis.md` 与 `.claude/shared/contracts/evidence-and-verification.md` 为准。
